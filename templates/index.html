About

This tool analyzes Malayalam text to determine sentiment (positive, negative, or neutral) using machine learning.

Contact: teamsentapi@gmail.com

Developed by: Vishnu N, Sreerag E, Firdousa K

API Access

Use SentAPI programmatically via the JSON endpoint:

POST /api/analyze Content-Type: application/json {"text": "ഈ സിനിമ വളരെ നന്നായിരുന്നു"}

Response:

{"prediction": "positive", "confidence": 92.5, "text": "..."}

Batch: POST /api/batch with {"texts": ["...", "..."]} (max 20)

Batch Analysis

One text per line (max 20), then analyze all at once.
